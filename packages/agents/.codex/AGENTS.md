# Codex preferences

## Tool preferences

- For any task that requires a manipulation for browsing, use `@Browser` by default.
- Do not use Playwright, Puppeteer, Selenium, or browser automation scripts unless I explicitly ask for them.
- If `@Browser` is not enough, explain why before using another tool.
- Do not use `@Browser` just for documentation or simple task, it's just required for frontend task
